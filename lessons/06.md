# Урок 6. Шарды датасета

Тег: [`lesson-06`](https://github.com/astropsy999/llm-from-scratch/tree/lesson-06)

Статья: [Урок 6. Почему dataset нужно дробить на shards](https://stuzhuk.page/ru/blog/llm-from-scratch-06-shards/)

## Что появилось

- `src/create_shards.py` — построчная нарезка JSONL, хвост, `metadata.json`
- `src/read_shards.py` — `iter_shards` через `sorted(glob(...))`
- `src/verify_shards.py` — число, порядок (MD5), дубликаты
- `data/shards/train/` — учебные шарды с `--shard-size 2`

Источник — `data/processed/train.jsonl` из урока 4.

## Команды

```bash
python src/create_shards.py \
  --input data/processed/train.jsonl \
  --output data/shards/train \
  --shard-size 2

python src/read_shards.py
python src/verify_shards.py
```

На большем корпусе можно поднять `--shard-size` (например, `100` или `1000`).
