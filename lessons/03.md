# Урок 3. BPE-токенизатор

Тег: [`lesson-03`](https://github.com/astropsy999/llm-from-scratch/tree/lesson-03)

Статья: [Урок 3. Пишем настоящий токенизатор: BPE на практике](https://stuzhuk.page/ru/blog/llm-from-scratch-03-tokenizer/)

## Что появилось

- `data/tokenizer_corpus.txt` — учебный корпус
- `src/train_tokenizer.py` — обучение BPE, `vocab_size=300`
- `src/test_tokenizer.py` — загрузка и `tokens` / `ids` / `offsets`
- `src/inspect_vocab.py` — размер словаря и спецтокены
- `src/probe_inputs.py` — разные типы входа и `[UNK]`
- `src/compare_vocab_size.py` — сравнение `vocab_size=100` и `500`
- `tokenizer/tokenizer.json` — сохранённый артефакт
- зависимость `tokenizers` в `requirements.txt`

## Команды

```bash
python -m pip install tokenizers
python src/train_tokenizer.py
python src/test_tokenizer.py
python src/inspect_vocab.py
python src/probe_inputs.py
# опционально:
python src/compare_vocab_size.py
python src/train_tokenizer.py   # вернуть основной tokenizer.json
```
