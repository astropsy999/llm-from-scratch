# Урок 16. Training loop как в реальном проекте

Тег: [`lesson-16`](https://github.com/astropsy999/llm-from-scratch/tree/lesson-16)

Статья: [Урок 16. Пишем training loop как в реальном проекте](https://stuzhuk.page/ru/blog/llm-from-scratch-16-training-pipeline/)

## Что появилось

- `configs/gpt-small.yaml`
- `src/train.py` — config, experiment dir, val, clipping, checkpoint/resume, early stopping
- `src/plot_training.py`
- зависимости `PyYAML`, `matplotlib`

## Команды

```bash
python src/train.py --config configs/gpt-small.yaml
# resume: поднять num_steps в experiments/gpt-small/config.yaml, затем:
python src/train.py --config experiments/gpt-small/config.yaml \
  --resume experiments/gpt-small/checkpoints/latest.pt
python src/plot_training.py \
  --metrics experiments/gpt-small/metrics.jsonl \
  --out experiments/gpt-small/loss.png
```
