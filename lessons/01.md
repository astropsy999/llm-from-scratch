# Урок 1. Лаборатория

Тег: [`lesson-01`](https://github.com/astropsy999/llm-from-scratch/tree/lesson-01)

Статья: [Урок 1. Собираем компьютерную лабораторию для обучения LLM](https://stuzhuk.page/ru/blog/llm-from-scratch-01-lab/)

## Что появилось

- `requirements.txt` — строка `torch` (команду установки даёт [страница PyTorch](https://pytorch.org/get-started/locally/))
- `src/check_pytorch.py` — версия и умножение тензора на 2
- `src/gpu_info.py` — видит ли сборка CUDA
- `src/check_gpu_operation.py` — перенос тензора на карту и matmul
- `src/check_environment.py` — одна сводная проверка
- `experiments/benchmark_cpu_gpu.py` — замер CPU / GPU с `synchronize`
- пустые `data/`, `notebooks/`

## Команды

```bash
python src/check_pytorch.py
python src/gpu_info.py
python src/check_gpu_operation.py
python src/check_environment.py
python experiments/benchmark_cpu_gpu.py
```

## Ожидаемое

- С CUDA: `Tensor test: OK`, `GPU test: OK`, в замере строки `CPU` / `GPU` / `Speedup`
- Без CUDA: `GPU test: SKIPPED`, в замере `GPU: SKIPPED`, без трассировки стека
