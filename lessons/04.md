# Урок 4. Первый датасет и JSONL

Тег: [`lesson-04`](https://github.com/astropsy999/llm-from-scratch/tree/lesson-04)

Статья: [Урок 4. Собираем первый датасет для LLM и разбираем формат JSONL](https://stuzhuk.page/ru/blog/llm-from-scratch-04-dataset-jsonl/)

## Что появилось

- `data/raw/document_01.txt` … `document_04.txt` — учебные исходники с шумом и дубликатами
- `src/prepare_dataset.py` — очистка, фильтр длины, точная дедупликация, split, JSONL
- `data/processed/train.jsonl` и `data/processed/validation.jsonl` — артефакты после запуска

## Команды

```bash
python src/prepare_dataset.py
test -f data/processed/train.jsonl
test -f data/processed/validation.jsonl
```

Повторный запуск с тем же `data/raw/` и `RANDOM_SEED=42` даёт тот же split.

Parquet, WebDataset, шарды, tokenization датасета, DataLoader, обучение модели.
