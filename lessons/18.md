# Урок 18. Mixed Precision

Тег: [`lesson-18`](https://github.com/astropsy999/llm-from-scratch/tree/lesson-18)

Статья: [Урок 18. Mixed Precision](https://stuzhuk.page/ru/blog/llm-from-scratch-18-mixed-precision/)

## Что появилось

- `src/benchmark_precision.py` — одинаковый короткий прогон в `fp32` / `fp16` / `bf16`
- `src/compare_precision.py` — таблица и графики из `experiments/precision/`
- `configs/gpt-amp.yaml`

## Команды

```bash
python src/benchmark_precision.py --config configs/gpt-amp.yaml --precision fp32
python src/benchmark_precision.py --config configs/gpt-amp.yaml --precision fp16
python src/benchmark_precision.py --config configs/gpt-amp.yaml --precision bf16
python src/benchmark_precision.py --config configs/gpt-amp.yaml --precision fp16 --probe-dtypes
python src/compare_precision.py
```
